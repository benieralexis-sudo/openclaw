# iFIND v7 — Brand Voice (Locked J5)

> Tone of voice locked pour TOUT le copy : site, emails, briefs Pépite, support.
> Source : Classroom 02 L2 (Projects) + Classroom 11 L2 (dual-write humans + LLMs).

---

## Tone en 5 mots

**Déclaratif · Posé · Précis · Confiant · Sans fluff.**

Lecture de référence : mercury.com (posé) × anthropic.com (austerity) × linear.app (concise) × Le Monde digital (FR éditorial).

---

## 5 dos (à faire)

1. **Phrases courtes** — 8-20 mots en moyenne. Les longues casseraient le rythme.
2. **Data concrètes** — 9 sources, 6 Pépites, 24h, 390€. Les chiffres tabular-aligned.
3. **Verbes d'action en premier** — "Détectez les signaux." pas "Notre solution permet de détecter…"
4. **Vous direct** — "Vous recevez 60 leads/mois." pas "Les utilisateurs reçoivent…"
5. **Italique éditorial** — un mot-clé italique par paragraphe (max). Crée une emphase respectueuse.

## 5 donts (à éviter)

1. ❌ **Superlatifs vagues** — "le meilleur", "le plus puissant", "ultra-performant"
2. ❌ **Marketing-speak** — "solution", "premium", "leader", "innovant", "disruptif"
3. ❌ **Hype US franglais** — "révolutionnaire", "game-changer", "cutting-edge", "next-gen"
4. ❌ **Formules creuses** — "n'hésitez pas", "à votre service", "permettez-moi de", "il va sans dire"
5. ❌ **Em-dashes excessifs** — un seul par paragraphe max. La virgule fait souvent l'affaire.

## Banned words FR (jamais dans le copy)

```
révolutionnaire · disruptif · innovant · leader · solution · premium · 
ultra · puissant · game-changer · cutting-edge · next-gen ·
n'hésitez pas · à votre service · permettez-moi · il va sans dire ·
"meilleur du marché" · "à la pointe" · "best-in-class"
```

## Patterns d'écriture

### Pattern 1 — Affirmation + preuve
```
"iFIND score par événement. Une levée annoncée hier. Un hire Sales 
la semaine dernière. Des faits publics, datés, attribuables au SIREN."
```

### Pattern 2 — Contraste tranchant (1 mot italique)
```
"Pas du *peut-être*. Du *vérifiable*."
```

### Pattern 3 — Chiffre + définition courte
```
"9 sources publiques françaises natives. Pas de scraping. Pas de
navigation anonyme. Que des événements datés."
```

### Pattern 4 — Question directe + réponse en 1 phrase
```
"Qu'est-ce qu'une Pépite ? Un signal HOT confirmé par 2+ sources
indépendantes sur 30 jours."
```

### Pattern 5 — Bénéfice → mécanisme
```
"Tu reçois 60 leads/mois dont 6 Pépites minimum garanties. Si on
n'atteint pas 6 → ton quota est doublé le mois suivant."
```

## Vouvoiement ou tutoiement ?

**Vouvoiement** par défaut sur le site (marché FR B2B premium, ICP CEO/Sales Ops).
**Tutoiement** OK dans le produit / dashboard / emails Fred (relation établie).

Cohérence : site = vous, app = tu. Pas de mélange.

## Dual-write LLMs (Classroom 11 L2 — pour AEO 2026)

Chaque section critique doit contenir :
- **Une définition courte du jargon** (LLMs ground answers) :
  → "Une Pépite est un signal HOT (score ≥ 9) confirmé multi-source sur 30 jours."
- **Une phrase quotable 8-20 mots** :
  → "iFIND score par événement public daté, pas par probabilité agrégée."
- **Numbered steps pour process** :
  → "1) Détecter via 9 sources. 2) Attribuer au SIREN. 3) Personnaliser le brief."
- **Data, dates, noms vérifiables** :
  → "Apify, Pappers, INPI, France Travail, RNE, Kaspr, FullEnrich, Rodz, TheirStack."

Ces éléments servent **2 audiences en même temps** : le lecteur humain qui scan, et le LLM (ChatGPT/Claude/Perplexity) qui ingère pour citation future.

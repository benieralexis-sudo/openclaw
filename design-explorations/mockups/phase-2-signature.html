L'asset signature — la forme d'onde de la marque.

L'asset signature est l'élément graphique le plus puissant de l'identité iFIND. Une forme d'onde sismographique en ambre qui apparaît sur le site, les decks, les vidéos, les signatures email, les posts sociaux. Cette page présente 5 variantes du motif, puis 6 applications concrètes, puis la spec technique pour qu'à terme cet asset soit généré procéduralement à partir des vrais triggers iFIND du jour — le killer move inimitable.

// VARIANTE V1 — NOMINALE
Onde calme avec pics ponctuels
amplitude · 20px · density · faible
Baseline cool calme + 3 pics francs sur 920px. Latence respiratoire entre les triggers. C'est la variante par défaut — utilisée en hero du site et fond de cartes.
// VARIANTE V2 — DENSE
Onde organique multi-pics (journée chargée)
amplitude · 30px · density · forte
Onde plus chargée : ~7 pics + micro-oscillations continues. Évoque une journée à fort volume de triggers. À utiliser pour stats annuelles / KPIs cumulés.
// VARIANTE V3 — SOBRE
Silence éditorial + 2 pics francs
amplitude · 35px · density · minimale
Onde quasi-vide avec 2 pics dramatiques. L'élégance du silence. À utiliser pour les supports premium éditoriaux : pitch deck cover, vidéo intro, page « Méthode ».
// VARIANTE V4 — HOT (PÉPITE URGENTE)
Onde nominale + pic bordeaux dominant
amber + bordeaux · pour Pépite HOT uniquement
Onde de fond en ambre atténué + 1 pic bordeaux dominant (couleur sémantique « alert-hot »). Réservé aux Pépites urgentes / alertes deadline. Communique « URGENCE » sans mot.
// VARIANTE V5 — MULTI-COUCHES
Signal principal + noise floor (sur fond ink)
ambre saturé + cream-warm atténué
Le plus sophistiqué : une couche de bruit de fond (le réel quotidien) + un signal franc qui se distingue. Idéal pour démontrer la valeur « on filtre le bruit pour extraire le signal ». À utiliser sur fond sombre.

3 · Spec technique pour génération procédurale

Phase 4 · branchement DB
// ROADMAP PROCÉDURAL — KILLER MOVE

L'asset signature généré depuis les vrais triggers iFIND du jour

À terme (Phase 4 du site v6), cet asset n'est plus statique : il est généré en temps réel à partir de la table Trigger de la base iFIND. Le hero du site change selon les vrais signaux détectés ce jour-là.

Pourquoi c'est inimitable : aucun concurrent (Pharow, Apollo, Cognism) n'a la donnée propriétaire pour faire ça. Ton identité visuelle DEVIENT la preuve de ton produit.

  • Endpoint suggéré : GET /api/signature/today.svg?width=920&height=100
  • Cache : 5 min (les triggers arrivent en quasi-temps réel mais 5 min suffit pour la fraîcheur perçue)
  • Mapping type → amplitude : funding_recent → 40px, c_level_move → 32px, hiring → 22px, INPI → 18px
  • Mapping score → couleur : >=90 amber saturé, 80-89 amber nominal, <80 amber dilué
  • Mapping urgence → palette : Pépite HOT → pic bordeaux #7A2E2E (variante V4)
  • Format de sortie : SVG inline (web) · PNG 2x (social) · ASCII (email alerte)

Implémentation côté backend : ~80 lignes de TypeScript dans /api/signature. Estimation : 4-6h de dev en Phase 4 quand on construit le site v6.

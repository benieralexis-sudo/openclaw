## 6. La recommandation finale tranchée

### TU GARDES la direction A (Sismographe Vélin & Ambre INPI) avec 3 évolutions ciblées

#### Évolution n°1 — Typographie : casser le piège "Geist Vercel"

**Avant** :
```
Display + Headings : Geist Variable
Body : Geist Variable
Mono : Geist Mono
```

**Après** :
```
Display (Hero h1, h2) : PP Editorial New (free-to-try Pangram)
                         OU Söhne Display (Klim, payant ~250€)
Headings (h3, h4) : Geist Variable Medium (gardé)
Body : Geist Variable Regular (gardé)
Mono (data, tabular) : Geist Mono Regular (gardé)
```

**Pourquoi** : Geist seul = look "Vercel/Linear/Resend" générique. Une typo display éditoriale signe "magazine premium éditorial" — exactement le positionnement Vélin. Pangram Editorial est gratuite à tester en localhost.

#### Évolution n°2 — Couleur d'urgence ponctuelle

**Ajout aux tokens** :
- `--alert-pulse: #FF4D2E` (rouge corail, vif mais raffiné)

**Usage** :
- ❌ JAMAIS sur un fond, JAMAIS sur du texte permanent
- ✅ UNIQUEMENT sur les pics sismographe quand un trigger arrive en live (pulse 800ms puis fade vers amber)
- ✅ Sur le compteur "412 triggers · 30j" quand un nouveau trigger apparaît
- ✅ Sur le bouton "ESSAYER" au hover (très subtil, après halo amber)

**Pourquoi** : tu gardes l'identité posée Vélin (calme, raffiné) MAIS tu introduis une **micro-tension** qui dit "ça vit, ça détecte, ça pulse". Résout l'antinomie "calme institutionnel vs urgence commerciale".

#### Évolution n°3 — Ton du message principal

**Avant** :
> "iFIND — Le sismographe de la donnée commerciale française"
> "Détection temps réel des triggers d'achat sur les PME tech FR. 9 sources souveraines, 13 patterns propriétaires. Aucun intent data américain."

**Problème** : trop conceptuel ("sismographe" + "triggers d'achat" = jargon). Pas de bénéfice clair.

**Après** (hypothèse à valider) :
> **"Détectez les PME tech FR qui s'apprêtent à acheter — avant vos concurrents."**
> 
> *Le sismographe iFIND capte les signaux d'achat des PME tech françaises 24/7 : levées, recrutements C-level, dépôts INPI. 9 sources officielles. Aucun intent data américain. 6 Pépites garanties par mois ou crédits doublés.*
> 
> *[Essayer 14 jours gratuits]  [Voir comment ça marche]*

**Apport** :
- Verbe d'action en hero (Détectez)
- Bénéfice concret immédiat (avant vos concurrents)
- Structure "feature → benefit" : sismographe → 24/7 levées/recrutements/INPI
- Garantie tangible : 6 Pépites garanties (ROI clair)
- CTA personalized
